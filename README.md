# mindful-app

マインドフルネスを継続し、**気分の数値がどう変化するかを自分のデータで検証する**個人用アプリ。

- iPhone のホーム画面から使う Web アプリ
- 記録は Google スプレッドシートに貯まる
- その日の記録が0件なら、夜にメールで通知

## 構成

```
iPhone Web アプリ → GAS Web App → Google スプレッドシート
                                        ↑
                            GAS 時間トリガー（毎晩21時・未記録ならメール）
```
