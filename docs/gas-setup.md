# GAS（保存先）のセットアップ手順

ここはあなたご自身の操作が必要な部分です。難しい言葉は使わず、上から順にやればOKな形にしています。

## 1. スプレッドシートを作る

1. Googleドライブで新しいスプレッドシートを作る
2. シート（タブ）の名前を「**記録**」に変更する（漢字2文字。間違えると保存できません）
3. 1行目（見出し行）に、左から順にこの9つを入れる

   ```
   timestamp | type | score | session_id | duration_min | label_kangae | label_fuan | label_keikaku | memo
   ```

## 2. GASのコードを貼り付ける

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
2. 最初から入っている `myFunction` などのコードを全部消す
3. このリポジトリの `gas/Code.gs` の中身を全部コピーして貼り付ける
4. 上部の保存アイコン（フロッピーの絵）をクリックして保存する

## 3. 合言葉（パスワード代わり）を設定する

1. Apps Scriptの画面の左側にある歯車アイコン「プロジェクトの設定」を開く
2. 一番下の「スクリプト プロパティ」で「スクリプト プロパティを追加」をクリック
3. プロパティ名に `SECRET`、値に好きな合言葉（例：自分だけがわかる英数字）を入れて保存する
   - ⚠️ この合言葉は誰にも教えないでください

## 4. Webアプリとして公開する

1. Apps Scriptの画面右上の「デプロイ」→「新しいデプロイ」をクリック
2. 種類の選択で「ウェブアプリ」を選ぶ
3. 「次のユーザーとして実行」→ 自分
4. 「アクセスできるユーザー」→ **全員**（これを選ばないとアプリから保存できません。合言葉で最低限のガードをしています）
5. 「デプロイ」をクリックし、出てきた**ウェブアプリのURL**をコピーする
   - 見た目：`https://script.google.com/macros/s/～/exec`

## 5. アプリ側に設定を入れる

1. このリポジトリのフォルダに `config.example.js` というファイルがあります
2. これをコピーして、同じ場所に `config.local.js` という名前で保存する
   （`config.local.js` は `.gitignore` に入っているので、GitHubには上がりません）
3. `config.local.js` の中身を書き換える

   ```js
   window.APP_CONFIG = {
     gasUrl: "手順4でコピーしたウェブアプリのURL",
     secret: "手順3で決めた合言葉"
   };
   ```

4. `index.html` をブラウザで開いて、瞑想の流れを最後までやってみる
   - 結果画面に「保存しました」と出れば成功
   - 赤字で「保存に失敗しました」と出た場合は、URLや合言葉が正しいか見直してください
5. スプレッドシートに新しい行が増えているか確認する

## つまずきやすいポイント

| 症状 | 原因の可能性 |
|---|---|
| 「合言葉が違います」と出る | `config.local.js` の `secret` と、GAS側の「スクリプト プロパティ」の `SECRET` が一致していない |
| 「シート「記録」が見つかりません」と出る | シート（タブ）名が「記録」になっていない |
| 何も反応しない・通信エラー | `gasUrl` の貼り間違い、または「アクセスできるユーザー」が「全員」になっていない |
| コードを直したのに反映されない | 「デプロイ」→「デプロイを管理」→ 鉛筆アイコンで「新しいバージョン」を選んで再デプロイが必要（URLは変わらない） |

⚠️ 実際にGoogleアカウントでの操作・デプロイは私（Claude）側では行えないため未検証です。うまくいかない場合は、出ているエラーメッセージをそのまま教えてください。
